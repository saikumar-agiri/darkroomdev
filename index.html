// about

// projects

chaos-creation homelab · personal infra
↗ github   ↗ read writeup

Fully automated homelab built on a single bare-metal AMD Ryzen 3 machine running Ubuntu 24.04. The entire stack — from OS prep to running services — is provisioned with Ansible playbooks, no manual steps. Runs a K3s cluster with Traefik ingress, a Grafana + Prometheus monitoring stack, Jellyfin media server, Uptime Kuma, and a Homepage dashboard. If the machine crashes, 9 playbook runs restore everything from scratch.

homelab · security layer in-progress · hardening

Next phase of chaos-creation focused on locking it down: Tailscale for zero-trust remote access, cert-manager + Let's Encrypt for HTTPS across all services, UFW firewall rules, Ansible Vault for encrypting secrets at rest, and Fail2ban for brute-force protection. Because a homelab without security is just a homelab waiting to be compromised.
